## 성과급 범위

메인 카드·연간 표·차트·배수·시나리오 비교·JSON·CSV의 성과급은 **OPI1+OPI2+PSU**입니다. 월급·고정수당·TAI는 제외하며 마지막 전체 보상 요약에서 함께 표시합니다. PSU는 기존 연도별 세후 가치를 한 번만 더하고, 지급/과세연도와 매도제한 해제연도는 구별합니다. PSU 포함 체크,0배 또는 달성 가정을 존중합니다. 제한 해제분만 해당 연도 현금화에 포함합니다.

## 두 전망 모드

선택은 **증권가 평균 / 사용자 지정** 두 가지입니다. 현재 시나리오 입력 프리셋과 연도별 프리셋을 삭제했습니다. 증권가 평균 모드는 출처를 참고하는 기존 계획 모드입니다. **계산에 사용하는370/550/500/518/466조원은 이번 수정에서 변경하지 않았으며 그 수치를 실제 시장 평균으로 인증하지 않습니다.**

2026년370조원은 사용자 계획값,2027년550조원은 시장 전망 근처의 반올림 계획값,2028년500조원은 하락 계획값,2029년518조원·2030년466조원은 연장 계획값입니다. 각 연도 입력 표에 자료 구분을 표시합니다.2028 이후 시장 평균은 확인되지 않았습니다. 자동 최신 전망 수집은 없습니다.

[유안타2026-09-23 보고서](https://file.myasset.com/sitemanager/upload/2026/0923/071649/20260923071649410_0_ko.pdf)의 Bloomberg2026-09-22 기준2027년 전체 연결 영업이익 평균566.349조원은 참고 자료입니다. 현재 계산값550조원과 다릅니다. DS 자체 영업이익으로 바꾸거나 연결→DS 환산비를 만들지 않았습니다.

사용자 지정에서는 연도별 전망을 직접 입력합니다. 모드 전환 시 다른 모드의 숫자는 유지합니다. 구형 중간/하락/사용자 지정 상태는 적용 중이던 값을 사용자 지정으로 이관하며 나머지는 legacyScenarioInputs에 보존합니다. 삭제된 모드는 화면에 다시 나타나지 않습니다. 가져온 평균 모드의 값이 기존 계획값과 다르면 사용자 지정으로 보존합니다.

## 계약연봉과 업무성과급

기존 opi2Policy.workBonusByYear 필드를 개인 입력 첫 영역 및 연도별 표에 노출했습니다. 금액은 원 단위 정수이며 화면 입력은 만원입니다. **OPI1 기준 = OPI2 기준 = 배수 분모 = 해당 연도 계약연봉+업무성과급.** 기존 원장의 basis가 이미 합계면 업무성과급을 다시 더하지 않습니다.

업무성과급은 기존 정의대로 성과급 산정 기초금액 전용이며 별도 현금 수입으로 재합산하지 않습니다. 연도별 직접 입력, 기본0원입니다. 연봉 인상률과 상한은 계약연봉에만 적용합니다. 학술연수 규칙과 PSU 지급 규칙은 유지합니다.

이전 저장 구조에서 계약연봉은 독립 필드, 업무성과급은 별도 연도별 필드였습니다. 포함 합계라는 표식은 없었습니다. 업무성과급 필드가 없는 저장값은0원으로 두므로 기존 연봉을 임의로 분해하거나 중복 가산하지 않습니다. 별도 금액이 있으면 보존합니다. 사용자가 과거 계약연봉 칸에 이미 합계 금액을 직접 적었다면 자동 판별할 수 없으므로 순수 계약액과 업무성과급으로 나누어 입력해야 합니다.

고정수당 포함 선택 UI는 삭제했습니다. 구형 includeAllowance=true도 무시하며 OPI1·TAI·OPI2 산정에는 고정수당을 넣지 않습니다. 수당 금액과 급여·과세소득은 유지합니다. 수당 변경으로 세후 세금은 달라질 수 있습니다. TAI 기준은 계약연봉입니다.

2026년 발생(세전/세후)과 현금화(세후)에 표시 금액÷기준 연봉의 배수를 표시합니다. PSU가 해당 연도에 발생/현금화되면 각 분자에 포함합니다. 급여 자체는 분자에 넣지 않습니다. 분모0은 배수 계산 불가입니다.

## OPI2·세금·보험 가정

기부0원 고정이며 선택 UI는 없습니다. 구형 기부율·manualGrossByYear는 무시합니다. OPI2는 **7.1억원 × 전사 연결 영업이익/370조원 × (계약연봉+업무성과급)/8,000만원 × 사업부 계수 × 학술연수 계수**인 기사 사례 기반 계획용 비례모델입니다. 공식 회사 산식이나 확정 지급률이 아닙니다.

[세계일보2026-10-10 보도](https://www.segye.com/newsView/20261010501154)의 7.5억/5.3억/2.4억원은 OPI1+OPI2 총액이며 PSU를 포함하지 않습니다. 정확한 기준 연봉은 미확인입니다. 계산은 8,000만원·OPI1 50%를 가정하여 메모리 OPI2 7.1억원만 기준으로 삼습니다. 공통0.70·파운드리0.30을 유지하면 합계7.5억/5.37억/2.53억원이며 기사와0/700만/1,300만원 차이가 납니다. 다른 부서 계수를 역산하지 않았고, 40%/60% 이익 풀 배분도 인원·급여총액이 없어 계산하지 않습니다. 공통70%는 보도에 나온 근사 배분 수준, 파운드리30%는 기존 계획 가정이며 둘 다 연도별 확정 지급률이 아닙니다. 이후 연도 비례 외삽은 사용자 계획 가정입니다. 공개 union-example-validation.json과 화면 비교표에서 차이를 확인할 수 있습니다.

DS 지급 문턱은 전사 전망과 독립적입니다. 연도별 DS 영업이익을 직접 입력하며2026–2028년200조원,2029–2030년100조원을 기본 문턱으로 사용합니다. DS 미입력 시 기본으로 체크된 **문턱 충족 가정**을 명시합니다. 체크를 끄면 판정 대기로 제외한 부분합계를 보여주며 0원 확정으로 취급하지 않습니다. 전사370조원만으로 DS 문턱을 통과시킨 것이 아닙니다.

세후 경제가치(주식+예상 정산 차액), 선징수 후 실제 지급 주식가치 가정, 연도별 현금화 가능액을 구분합니다. 메모리 기사 예시의 OPI2 7.1억원 선징수49.5%·4.967% 후 주식가치는323,284,300원이며 첫 회차107,761,434원입니다. 기사 첫 회차 반올림과1원 차이가 나며 정확한 원 단위 분배를 보존합니다. OPI1 세후는 지급연도 최종 연간 증분 세금/보험료 안분 추정으로 실제1월 급여 입금액이 아닙니다. 전체2027년 과세소득 정산은2028년2월, 보험 차액은4월이라는 계획용 일정이고2027년 보험료율과 실제 회사 정산일은 미확인입니다. 환급은 주식 회차에 합쳐 다시 분할하지 않습니다.

저장 조건은 연봉·업무성과급·PSU·전망·세금 설정을 유지합니다. opi2ModelRevision:2로 모델을 이전하고 이전5.4억원/300조원/8,500만원 기준은 legacyOPI2Model에 보존합니다. DS 금액·충족 가정도 JSON/로컬 저장소로 보존하며 개인 입력을 서버로 전송하지 않습니다.

사용자가 전달한2026-10-07 회사 안내의 OPI2 지급연도 귀속, 소득세/지방소득세49.5%·보험4.967% 선징수를 가정합니다. 보편적인 상여금 법정 고정세율을 뜻하지 않습니다. 그 해 OPI1·TAI·OPI2·PSU를 모두 더해 급여 기준 대비 증분 세금/보험을 각각 한 번 계산하고, 세전 과세소득 비례 최대잔여법으로 원 단위 합계를 보존합니다.

OPI2 세금 정산=선징수 세금−안분한 최종 증분 세금, 보험 차액=선징수 보험−안분한 최종 보험. 양수는 환급, 음수는 추가납부입니다. 세금은 과세 다음 해2월, 보험은 지급 다음 해4월의 계획 가정이며 삼성 실제 입금일은 미확인입니다. 정산 현금으로 주식수/매각 회차금액을 늘리지 않습니다. PSU는 기존 지급연도 과세·세후 주식가치를 사용하며 별도 OPI2 선징수를 반복하지 않습니다.

기간 밖 현금화는 제외하고 미지급 주식·이미 지급된 매도제한 주식·미지급 OPI1·정산 채권/채무를 나눕니다. 향후 연봉은 같은 인상률·상한으로 외삽하고 보험/세율은 설정을 유지합니다. 입력 이전 보상은0원, 좁힌 기간의 이전 입력분은 기초잔액입니다.

### 2026년 세후 총 성과급 표시

첫 결과 카드의 단일 강조 합계는 `세후 총 성과급 · OPI1+OPI2+PSU`입니다. OPI1의 현금 지급분을 포함한 OPI1+OPI2+PSU 세후 발생액 전체를 합산합니다. 이전 별도 OPI2·PSU 주식가치 소계는 제거해 전체 성과급과 혼동하지 않게 했습니다. 월급·고정수당·TAI는 이 합계에서 제외합니다. OPI2는 기존 세후 발생가치와 예상 현금 정산을 포함하며 PSU는 기존 세후 발생가치를1회 포함합니다. 세금 계산을 다시 하거나 지급·매각 시점을 바꾸지 않습니다. 실제 현금화 가능액은 별도입니다.

배수는 `세후 총 성과급 ÷ (계약연봉+업무성과급)`이며 금액 뒤 `(X.XX배)`로 표시합니다. 세전·세후 표시가 명시된 다른 항목은 각각 표시된 금액을 같은 분모로 나눕니다. 분모0은 `(계산 불가)`입니다. 고정수당은 분모에서 제외합니다. 모바일에서도 배수의 괄호는 중간에서 끊기지 않습니다.
